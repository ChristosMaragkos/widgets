# Widgets

Widgets is a simple UI library written for [BHMTH](https://github.com/ChristosMaragkos/behemoth).

It contains code for horizontal and vertical sliders, buttons, toggle buttons, and labels with arbitrary colors (even rainbow for text!)

Controls:
- Use L/R for previous/next widget
- Up/Down for vertical sliders
- Left/Right for horizontal sliders
- A for buttons and toggles

Limitations:
- Widgets must be laid out in memory in the same order you want to navigate them, from first to last
- Widgets must be transferred to RAM on boot to manipulate their color
